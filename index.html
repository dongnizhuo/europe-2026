Notes · 笔记 · 各国须知

Practical knowledge by country. 想加你自己学的笔记请告诉我.

🇬🇧 United Kingdom 英国
货币 / Money
英镑 GBP £ · 北爱苏格兰部分自印钞票 (英国全境通用但欧陆不收). 几乎所有地方刷卡, 现金只为小费/市集. 苹果/谷歌钱包覆盖率极高.
小费 / Tipping
餐厅账单常含 12.5% service charge, 含了就不另给; 没含可给 10-15%. 酒吧台点酒不需要小费. Taxi 凑整即可.
插座 / Plug
Type G 方头三相 · 230V / 50Hz · 必须带转换插
交通 / Transit
伦敦地铁/巴士/DLR/Overground 用 Contactless 信用卡或 Apple Pay 直接刷, 自动按当日封顶价收费. 不要买 paper ticket. 苏格兰内 ScotRail 火车提前买便宜.
习俗 / Etiquette

📌 通用提示 Universal Tips
护照 / Passport
随身带护照原件 + 另存彩色扫描件到手机和云盘各一份. 申根区内通常不查护照但仍需带. 英国不属申根, 入英境需护照查验.
通讯 / SIM
推荐 eSIM 提前购 (Airalo / Holafly / Saily 等). 欧盟单一资费, 英国常独立计费. 美国本号在欧洲资费高, 出发前问运营商欧洲漫游包.
退税 / VAT Refund
非欧盟居民单店满最低额度可退税. 商店要 tax-free 单 + 护照 · 离开欧盟最后一国机场盖章 · 在 Global Blue / Planet 柜台办退. 最后离境是罗马 FCO 飞成都, 在罗马办退税.
医疗 / Health
提前买全球旅行保险 (含医疗 + 行李 + 误机). 申根国家药房 (绿十字标志) 多, 处方药需医生开. 随身带常用药 (退烧 / 肠胃 / 过敏).
备份 / Backup
所有酒店地址 / 机票 / 预订 都下载离线备份到手机 (本手册即可!) · Google Maps 提前下载离线地图.
