Notes · 笔记 · 各国须知

Practical knowledge by country. 想加你自己学的笔记请告诉我.

🇬🇧 United Kingdom 英国
货币 / Money
英镑 GBP £ · 北爱苏格兰部分自印钞票 (英国全境通用但欧陆不收). 几乎所有地方刷卡, 现金只为小费/市集. 苹果/谷歌钱包覆盖率极高.
小费 / Tipping
餐厅账单常含 12.5% service charge, 含了就不另给; 没含可给 10-15%. 酒吧台点酒不需要小费. Taxi 凑整即可.
插座 / Plug
Type G 方头三相 · 230V / 50Hz · 必须带转换插
交通 / Transit
伦敦地铁/巴士/DLR/Overground 用 Contactless 信用卡或 Apple Pay 直接刷, 自动按当日封顶价收费. 不要买 paper ticket. 苏格兰内 ScotRail 火车提前买便宜.
习俗 / Etiquette
扶梯靠右站, 左侧给人走. 排队是国教 · 不要插队. 室内不能砍价. 司机靠左行驶, 过马路先看右.
紧急 / Emergency
999 或 112 · 中国驻英大使馆 +44 20 7299 4049 · 苏格兰爱丁堡总领馆 +44 131 337 9899
🇪🇸 España 西班牙
货币 / Money
欧元 EUR € · 卡支付普及 · 小餐馆/市场建议备零钱. ATM 取现注意手续费.
小费 / Tipping
不强制 · 满意凑整或留 5-10% 即可. 出租车凑整.
插座 / Plug
Type C/F 圆头双相 · 230V · 全欧陆通用
时间 / Schedule
西班牙吃饭晚: 午餐 14:00-16:00, 晚餐 21:00+. Siesta 13:00-17:00 小店可能关门. 餐厅 19:00 前可能根本没开门.
巴塞罗那特别提示
扒手警戒最高 ★★★ · La Rambla / 地铁 / 旅游景点最常见. 包前背 · 钱包不放后裤袋 · 拍照时手不离机. 加泰罗尼亚语和西语并行, 西语全境通行.
必尝 / Must-eat
Tapas · Paella (海鲜饭 - 注意正宗的中午吃) · Jamón ibérico 火腿 · Crema catalana · Vermut 开胃酒
紧急 / Emergency
112 全国通用 · 中国驻西大使馆 +34 91 745 8543 · 巴塞罗那总领馆 +34 93 254 1196
🇫🇷 France 法国 / 巴黎
货币 / Money
欧元 EUR € · 卡支付主流 · 小面包店仍可能只收现金或最低消费
小费 / Tipping
账单已含 service compris, 满意凑零钱或 1-2 欧即可. 计程车凑整.
插座 / Plug
Type C/E 圆头 · 230V
语言习俗 / Etiquette
进店务必先说 "Bonjour" · 离店说 "Au revoir". 不打招呼直接问问题被认为很无礼. 法国人很多会英语, 但请先尝试法语开头. 餐厅吃饭节奏慢, 不要催, 要主动招呼服务员买单.
巴黎特别提示
扒手 ★★★ · 地铁 1/4/8 号线 · 蒙马特 · 铁塔下小心 "签名请愿"/"金戒指" 骗局. 免费厕所: 教堂/百货公司/快餐店. 大博物馆周二很多关门, 周一也有不少.
交通 / Metro
Métro 系统密集易用 · Navigo Easy 实体卡或 iPhone 上 Navigo 钱包. 单程 t+ €2.15. 注意不同公司/线路:Métro vs RER vs Tramway.
紧急 / Emergency
112 通用 · 17 警察 · 15 医疗 · 中国驻法大使馆 +33 1 4936 7790
🇮🇹 Italia 意大利
货币 / Money
欧元 EUR € · 大店刷卡, 小餐馆/咖啡/出租司机可能优先现金. 备 €50-100 零钱.
小费 / Tipping
账单常有 "coperto" (人头费 €1-3) 和/或 "servizio" 服务费 — 这两项就替代小费了. 满意可再凑 1-2 欧.
咖啡习俗
早上 cappuccino, 10am 后改 espresso (本地人 11am 不喝奶咖啡). 站在吧台喝最便宜 (€1-1.5), 坐下加倍. 不说"latte"会被给一杯纯牛奶.
教堂着装 / Dress code
梵蒂冈 / 圣彼得 / 米兰主教座堂 / 佛罗伦萨主教座堂 等都要遮肩遮膝 · 短裤短裙背心进不去 · 带条围巾备用
交通 / Transit
城际首选高铁 Frecciarossa / Italo · 提前 1-2 月买价差极大. 火车票上车前打票 (Regionale 区间车) — 高铁不用. 罗马公交/地铁紧买紧用, 不打票会被罚.
扒手 / Pickpockets
罗马 Termini 车站 / 地铁 A 线 / 斗兽场周围 ★★★★ · 佛罗伦萨较弱 · 包要前背或斜挎不离手
紧急 / Emergency
112 通用 · 113 警察 · 118 急救 · 中国驻意大使馆 +39 06 9652 4200 · 佛罗伦萨总领馆 +39 055 5970640
📌 通用提示 Universal Tips
护照 / Passport
随身带护照原件 + 另存彩色扫描件到手机和云盘各一份. 申根区内通常不查护照但仍需带. 英国不属申根, 入英境需护照查验.
通讯 / SIM
推荐 eSIM 提前购 (Airalo / Holafly / Saily 等). 欧盟单一资费, 英国常独立计费. 美国本号在欧洲资费高, 出发前问运营商欧洲漫游包.
退税 / VAT Refund
非欧盟居民单店满最低额度可退税. 商店要 tax-free 单 + 护照 · 离开欧盟最后一国机场盖章 · 在 Global Blue / Planet 柜台办退. 最后离境是罗马 FCO 飞成都, 在罗马办退税.
医疗 / Health
提前买全球旅行保险 (含医疗 + 行李 + 误机). 申根国家药房 (绿十字标志) 多, 处方药需医生开. 随身带常用药 (退烧 / 肠胃 / 过敏).
备份 / Backup
所有酒店地址 / 机票 / 预订 都下载离线备份到手机 (本手册即可!) · Google Maps 提前下载离线地图.
